# Script: score the pilot and write the review routing

No model work. The `run` command rebuilds the calibration set (same seed, same key), scores each `(lens, model)` against the seeded faults, applies the routing rule of `tools/lens_routing.py` and writes `translation/review-routing.yaml` and `review/calibration-<date>.md`. The report is in English. It shows, for each lens, the recall, quote validity, format validity, cost per packet and cache-read share of each model, the model picked and why, and the Fable probe result (refused pages, if any).

The routing is applied without a human step (decision D5): the caps still limit the spend. Jim can read the report at any time and change the routing file in a commit before j02 runs.
