# Script: write the Fable report with PDF page and verified file and line

No model work. The `run` command checks each quote against its page text, finds it in the Spanish sources and the PO files, and writes `review/fable/report-<date>.md` (English; for each finding: severity, category, PDF and page, source file and line, PO file and line, problem, suggestion) and `review/fable/findings-<date>.jsonl`. A finding whose quote is not on its page or not in any source goes to the section "Unverified". It then writes the default routing `review/fable/routing-<date>.md` for step p05.
