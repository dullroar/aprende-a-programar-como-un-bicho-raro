# Script: write the inbox replies and ingest them into the report and the findings

No model work. The `run` command writes the replies of the jury and editorial lanes to `review/inbox/batch-*.md` (exactly as the models wrote them), checks the inbox, rebuilds the packets and runs `jury_ingest.py` through `gatelib.py ingest`: exact-quote check, canary recall for each juror, juror weights, merge of duplicates. It writes `review/report-<date>.md`, `review/findings-<date>.jsonl` (status `open`) and the record with `base-commit:` (the commit before any fix) and `failed-share:`.

## Done when

- The report has a recall line for each juror. Under 2 % of the W1 requests failed, or the record has `failed-accepted: <reason>` written by Jim.

## Record

The driver sets `status: done` and writes `evidence` when the gate passes. Do not edit this file to mark it done.
