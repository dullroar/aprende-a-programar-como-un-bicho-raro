# Operator: set the prices, the caps and the decisions, and start the submitter

Operator step. The driver checks the gate and does not start an agent. Jim does this by hand. It takes about 30 minutes.

## Actions

1. Read the OpenAI pricing page and the OpenAI Batch API page. Pick two OpenAI models for jurors: one low-cost, one mid-level. Neither may be a model that was used in the translation loop. Fill their rows in `translation/batch-prices.yaml` (replace every `SET-BY-JIM`). `python3 -I tools/batch_prices.py --check` must pass.
2. Write `plans/v4-es-1b/records/f02-operator-budget.md` with these lines (numbers in USD):
   - `cap-W0-usd:`, `cap-W1-usd:`, `cap-W2-usd:`, `cap-W3-usd:`, `cap-W4-usd:`, `cap-W5-usd:`, `cap-W6-usd:`, `cap-C-usd:` (see "Cost estimate" in `plan.md`; proposed: 10, 40, 15, 10, 5, 30, 10, 2).
   - `cap-anthropic-total-usd:` (proposed 100, the program cap) and `cap-openai-total-usd:` (proposed 40).
   - `openai-juror-low:` and `openai-juror-mid:` (the model IDs of step 1).
   - `d1-vendors:`, `d2-caps:`, `d3-humor-provisional:`, `d4-publication-later:`, `d5-unattended-submit:`, `d6-fable-minor-to-editors:`, each `yes` or `no` with a reason after ` - ` if `no`. The decisions are in `plan.md`, section "Decisions for Jim".
   - `submitter-started: <date>`.
3. If D2 raises the Anthropic total over USD 100, change `PROGRAM_CAP_USD` in `tools/batch.py` yourself in the same commit, with the date and the reason in the comment.
4. In the operator shell (with the keys), start the timer: `BATCH_SUBMITTER_UNATTENDED=1 python3 tools/batch_submitter.py run --once` every 10 minutes (the docstring of the tool has a cron line and a systemd user timer). Run `python3 tools/batch_submitter.py status` once to see that it works.
5. Commit on the step branch. Do not write a key, a path or a personal name.
