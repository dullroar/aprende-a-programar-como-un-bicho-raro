# Script: build the Jury packets twice and record their digest

No model work. This is step `j01` of `v4-es-1`. The `run` command builds the packets (prose and code, with the bundle and the canaries) twice into `.probe/`, checks that both builds have the same manifest digest, checks that `jury_packet.py` reports no `LEAK:` line, writes the digest to `plans/v4-es-1/records/j01-packets.md` (the fixed path of `gatelib.py`) and deletes `.probe/`.
