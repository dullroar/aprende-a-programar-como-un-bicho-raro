# Guide to the repository

This file is the index of repository documents for humans. The folder `docs/` is book content, not a document index.

- [`AGENTS.md`](./AGENTS.md): the rules for agents. Read it before you change the repository.
- [`plans/`](./plans/AGENTS.md): the work plans, one folder for each plan.
- [`memory/`](./memory/AGENTS.md): short facts that cost time to find.
- [`scripts/`](./scripts/AGENTS.md): scripts for agents and CI.
- [`translation/`](./translation/): the English source pin, the glossary and the translation records.
- [`loop/STATE.md`](./loop/STATE.md): the state of the old private loop.
