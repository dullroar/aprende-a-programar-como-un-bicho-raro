# Editorial review of *Aprende a programar como un bicho raro*

20 November 2026 · Spanish checkout `22e3a5f92f40d5a1fe8b863a02f8d11794fd8ef2` (`loop/es-v4`)

## Scope and priorities

I reviewed all **12 Markdown files with applied translations** in the working tree, plus the Spanish house style. The review covers grammar, idiom, terminology, register, technical references, Markdown, diagrams, and links. Locations refer to the working-tree files and use one-based line numbers. I screened the 250 Markdown files reported by Git against the English baseline after applying the repository’s path mapping. The available local English source matches the commit pinned in `translation/source.json`, `48a4429c0a22b2aac628b256a50c07d1816bcb80`. The Rust PO draft was present and the corresponding Markdown still matched English. The English-language plan and reports contain incidental Spanish examples. [Pinned English edition](https://github.com/dullroar/learn-programming-the-weird-way/tree/48a4429c0a22b2aac628b256a50c07d1816bcb80)

Fix **Technical** and **Link** findings first. In particular, the Forth README changes the unit of the shared challenge from hours per card to number of cards, and the LINQ variant A diagram fails to render. Diagram labels translate code in three places: Kotlin’s `also`, Python’s `step`, and LINQ’s `where` and `from persisted in`. **Source issue** identifies a problem or ambiguity also present in English. It should be tracked against the English edition so the two versions can be corrected together. Unlabeled items are language, style, or presentation edits.

**Form of address.** Keep **tú**, normally implicit. It fits advanced students and the author’s direct, humorous voice. Use *Lee*, *traza*, and *ejecuta* when assigning an action. Use indicative verbs with an explicit subject when describing a program, as in *El programa abre…* For outcomes governed by *deberías poder*, use infinitives. For headings, use an imperative for an action (*Traza una ejecución*) and a question or indirect question for an explanation (*Cómo funciona el truco*). No switch to *usted* or *vos* is warranted in the files reviewed. Leave literal dialogue and labels in their original form when they are program output.
